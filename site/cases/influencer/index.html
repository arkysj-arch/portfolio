인플루언서 제안 자동화

팔로워 수 대신 '구매 문의 댓글 비율'로 후보 선별부터 제안·출고까지 자동화한 CRM 파이프라인

01 문제

공구 성과는 팔로워 수가 아닌 '살 마음이 있는 팬'에서 나온다

공구 성과는 팔로워 수보다 '살 마음이 있는 팬'에서 나오는데, 후보 발굴·제안·샘플 출고를 사람이 반복한다 (루킨스 메가 공구 13억·23억 경험).

02 판단

단순 팔로워 수 배제, 진성 구매 댓글 비율과 90일 보호 규칙

팔로워 수 대신 구매 문의 댓글 비율로 후보 선별, 발송은 사람 확인 후, 90일 재제안 금지.

최근 릴스 3개의 실제 댓글을 모아 구매 문의 댓글의 비율을 본다. 이미 제안한 사람은 다시 분석하지 않고, 거절·수신거부는 종료로 닫아 다시 연락하지 않는다.

03 AI에게 시킨 것

수집·분석 엔진부터 CRM·메일·대시보드 구축

수집·분석 엔진(v2.0, Antigravity) → CRM·메일·대시보드(v3.0)

  • 1단계 발굴: 해시태그 → 프로필 → 릴스 → 실제 댓글 수집 및 구매 문의 댓글 비율 기반 ROI 점수 산출
  • 2단계 제안: 후보별 개인화 제안 메일 초안과 DM 문구 생성 (초안만, 발송하지 않음)
  • 3단계 발송: 담당자 최종 확인 후 발송 진행 (90일 재제안 금지 규칙 자동 적용)
  • 4단계 회신 분류: 수락 / 문의 / 거절 / 수신거부 자동 분류 및 수락 시 샘플 출고 단계 연계
  • 5단계 보고: 퍼널, 점수 구성, 메일 본문, 출고, 활동 로그를 한 화면 대시보드로
04 결과

처음부터 끝까지 한 흐름, 자동 테스트 통과

발굴→제안→회신 분류→출고까지 한 흐름, 테스트 42개 통과, 샘플 데이터 검증 (실운영 수치 없음 — 프로토타입으로 표기).

프로토타입 케이스 03

SJ RANK

진단에서 끝내지 않고 90일 실행 플랜과 우선순위까지 제시하는 B2B SEO 대시보드

01 문제

진단 결과만 나열하고 구체적인 실행 방안이 없는 SEO 도구

외부 채널 의존을 자사몰 수익으로 바꾸려면 검색 유입이 필요한데, SEO 도구는 점검 결과를 나열할 뿐 "그래서 무엇부터 하라는지"는 알려주지 않는다.

02 판단

진단에서 끝내지 않고 90일 실행 플랜까지, Google·Naver 동시 대응

진단에서 끝내지 않고 90일 실행 플랜(효과×심각도÷작업량 우선순위)까지, Google·Naver 함께.

단순 점수 측정을 넘어, 이미 4~20위에 있어 적은 작업량으로도 1페이지 진입이 가능한 빠른 성과 키워드를 먼저 선별하고, 주차별 체크리스트로 실행 순서를 구조화한다.

03 AI에게 시킨 것

대시보드·사이트 감사·키워드·순위 추적 화면과 진단 파이프라인

대시보드·사이트 감사·키워드·순위 추적 화면, 실제 진단(직접 크롤링 + DataForSEO 1회 약 $0.04).

  • 통합 대시보드 종합 현황: 건강 점수, 오가닉 트래픽, 순위 구간별 키워드 분포 차트, 코어 웹 바이탈
  • 90일 실행 플랜 우선순위화: 90일 목표 유입, 빠른 성과 키워드(4~20위) 선별, 4단계 12주 실행 체크리스트
  • 사이트 감사 기술 점검: 페이지별 상태 코드·온페이지 점수·제목 길이·H1 누락·로딩 속도, 검색 결과 스니펫 미리보기
  • 키워드 리서치 기회 발굴: Google·Naver 전환, 검색량·난이도·검색 의도 필터, 엑셀 한글 호환 CSV 다운로드
  • 순위 추적 경쟁 분석: 키워드별 현재 순위·전일 등락·30일 추이·랜딩 URL, 경쟁 사이트 2곳 비교

진단 다음까지

AI 전략·글 기획서·초안

진단 결과로 우선순위와 새 글 주제를 만들고, 기획서와 초안까지 작성. 무료 등급 AI, 유료 AI, 키 없이 쓰는 복사 모드 중 선택

발행 전 자동 검수

의약품 오인 표현·확인 안 된 내용은 차단, 기능성·최상급 표현은 주의. 라벨 문장 70개로 잰 재현율 98%·정상 문장 차단 0건 (처음 보는 문장에서는 더 낮음)

채널 변환과 자사 블로그 발행

네이버·Threads·인스타 카드뉴스로 변환, 승인된 글은 자사 블로그에 예약 발행하고 검색엔진에 색인 요청

사업 흐름 설계 (RankSeed)

무료 진단을 요금제·결제로 잇는 사업 흐름 설계 (공개 서비스의 흐름만 참고, 이름·디자인·문구는 새로 작성).

04 결과

진단부터 실행·발행까지 한 도구 구축, 데모 데이터 검증

실행 플랜·사이트 감사·키워드·순위 추적·발행까지 한 도구, 데모 데이터로 검증 (실사용 수치 없음 — 프로토타입).

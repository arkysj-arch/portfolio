## 3. 세부 변경 사항 점검
1. **맨 위 안내 상자**
   - 문구를 "메디큐브·달바와 무관한 비공식 포트폴리오 샘플입니다. 공식몰에 공개된 제품 사진을 썼고, 업로드·광고 집행은 하지 않았습니다."로 변경
2. **3단(AI에게 시킨 것)**
   - 기존 `.role-table-wrap` 바로 뒤에 블록 추가 (제목: `역할 분담 — 두 번째 영상(16:9 제품 광고)`)
   - Claude / Nano Banana 2.1 / Google Flow 영상 (Omni 1.2 Flash) / Flow Music 4행 표 추가
3. **4단(결과)**
   - 기존 `.limits-wrap` 바로 뒤에 `<h3 class="subsection-title" style="margin-top: 2.5rem;">두 번째 영상: 16:9 제품 광고</h3>` 추가
   - 신규 `.result-stats` 타일 4개 추가: `20초` / `6컷` / `72크레딧` / `12장 → 6장`
   - 신규 `.limits-wrap` 한계 4줄 추가 (4번 컷 캡 경첩 뚜껑, 라벨 작은 문구 AI 미표현, 720p → 1080p 업스케일, 성과 지표 없음)
4. **5단(직접 체험)**
   - 기존 첫 번째 영상 캡션 맨 앞에 `첫 번째 영상: 메디큐브 부스터 프로 X2(9:16). ` 추가
   - 기존 플레이어 뒤 `.demo-action-box` 앞에 달바 16:9 비디오 플레이어 블록 추가
5. **디자인 및 문장 규칙 준수**
   - `<head>`, 메타 태그, 1·2단 본문, 기존 메디큐브 수치 변경 없음
   - 지시서 외의 추가 설명 문단 없음
   - 꾸밈말(엄격히, 정밀, 투명하게, 완벽한, 혁신적, 보장 등) 배제
   - 외부 라이브러리 및 셸 명령 없이 순수 파일 수정 도구만 사용

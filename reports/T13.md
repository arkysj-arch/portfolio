## 1. 만든·고친 파일 목록

### 신규 생성 파일 (3개)
- `site/favicon.svg` — 32x32 기준 남색(#14213D) 둥근 사각형(rx: 7) 안에 아이보리(#F7F4EE) 글자 "윤" 배치 (외부 폰트 없이 sans-serif 사용)
- `site/404.html` — "찾는 페이지가 없습니다" 안내 문구와 [메인으로] 버튼(`href="./"`) 제공. 외부 CSS 링크 없이 내부 `<style>`만으로 디자인 토큰(아이보리/남색/테라코타) 적용
- `site/og/og.html` — 1200×630px 고정 공유 이미지 원판. "포트폴리오", "AI 팀을 지휘해 이커머스·마케팅 성과를 만드는 총괄", "윤성조 · 뷰티디바이스·화장품 이커머스 17년", 오른쪽 아래 테라코타 포인트 색 띠에 5개 케이스 명시

### 헤더 메타태그 추가 파일 (9개)
- `site/index.html`
- `site/cases/influencer/index.html`
- `site/cases/sj-proof/index.html` (noindex 포함)
- `site/cases/sj-rank/index.html`

# T03 작업 보고서: 메인 하단(경력 요약 · 그 밖의 작업 · 연락)

## 1. 만든 · 고친 파일 목록
- `site/index.html` (수정)
  - 헤더 네비게이션에 "경력" 메뉴 항목 추가 (`#projects`, `#career`, `#contact`)
  - 히어로 섹션 내 연락처 표시 및 `id="contact"`를 제거하고, `#contact` 섹션으로 이동하는 "연락하기" 버튼(`btn-primary`)으로 변경
  - 프로젝트 섹션 하단에 경력 섹션(`id="career"`), 그 밖의 작업 섹션(`id="others"`), 연락 섹션(`id="contact"`) 컨테이너 추가
- `site/assets/js/main.js` (수정)
  - 기존 프로젝트 렌더링 함수(`renderProjects`, `defaultProjects`) 유지
  - HTML 이스케이프 유틸리티 함수 `escapeHtml` 추가
  - `data/career.json`을 읽어 경력(`renderCareer`), 그 밖의 작업(`renderOthers`), 연락(`renderContact`) 섹션을 렌더링하는 함수 추가
  - 데이터 로드 실패 시 "경력 정보를 불러오지 못했습니다" 에러 메시지만 표시 (기본값 복사본 금지 규칙 준수)
- `site/assets/css/style.css` (수정)
  - 기존 스타일 규칙 수정 없이 파일 맨 끝에 새 섹션 스타일 추가
  - 하이라이트 타일(데스크톱 5열, 태블릿/모바일 2열), 세로 타임라인, 이전 경력 박스, 다운로드 버튼(비활성 상태 및 안내), 외부 링크 카드, 연락 카드 반응형 스타일 작성
- `reports/T03.md` (신규 생성)
  - 본 작업 보고서

## 3. [확인 필요] 목록, 남은 문제, 질문
- `[확인 필요]` **연락처 이메일**: `career.json`의 `contact.email`이 `null`로 지정되어 있어 현재 화면에 `[이메일 확인 필요]` 플레이스홀더로 표시되고 있습니다. 실제 연락을 수신할 이메일 주소 확인 및 업데이트가 필요합니다.
- `[확인 필요]` **경력 포트폴리오 PDF**: `downloads` 항목의 `href`가 `null`이므로 버튼이 비활성 상태(`is-disabled`, `disabled`)로 표시되며, 우측에 `공개용 버전 준비 중 (T11)` 안내 문구가 함께 출력됩니다. 향후 T11 작업 시 실제 다운로드 링크 연결이 필요합니다.

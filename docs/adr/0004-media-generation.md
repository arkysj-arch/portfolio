# 0004. 이미지·영상은 Claude가 Ego Lite로 생성, Gemini는 프롬프트 초안

상태: 결정 (2026-11-24)

## 맥락
Gemini CLI에는 이미지 확장이 없고 API 키도 없다. 오너는 브라우저 Ego Lite로 웹 생성 도구를 쓰길 원한다. Gemini CLI는 브라우저를 조작할 수 없다.

## 결정
- 도구 우선순위: 1순위 arena.ai → 2순위 Gemini Flow·Nano Banana → 그 밖의 무료 도구(생성 단계에서 조사해 추가)
- Gemini: 이미지 목록별 프롬프트 초안 작성 / Claude: 다듬기 → Ego Lite에서 생성 → 선택 → 압축·삽입
- 생성은 SPEC에서 확정한 목록만큼만 (화면 조작은 Claude 사용량이 크다)

## 결과
- 좋음: API 키·과금 없이 시작, 오너 계정의 도구 그대로 사용
- 대가: 각 도구의 이용 약관(상업적 사용, 공개 여부)을 생성 전에 확인해야 한다 [미확인]

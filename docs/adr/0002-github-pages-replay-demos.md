# 0002. GitHub Pages 배포, 데모는 전부 체험형(재생) 데모

상태: 결정 (2026-11-24)

## 맥락
인사담당자가 "실제로 작동하는지" 확인해야 한다. 원 프로젝트들은 서버와 유료 API 키(Apify, Gemini, DataForSEO, Stripe)가 필요하다. 공개 서버에 올리면 비용·남용·키 노출 위험이 있고, 무료 서버는 첫 응답이 느리다.

## 결정
GitHub Pages에 정적 사이트로 배포한다. 모든 데모는 **실제 실행 결과를 샘플 데이터로 담은 체험형 데모 + 1분 시연 영상**으로 만든다. RankSeed·SJ RANK의 실시간 진단도 쓰지 않는다.

## 결과
- 좋음: 비용 0, 키 노출 0, 항상 빠르게 열린다
- 대가: "실시간"이 아니므로 데모마다 "실제 실행 결과를 재생합니다"라고 밝힌다
- 되돌리려면: 실시간 진단은 별도 서버(Vercel 등)를 붙여 한 케이스만 추가할 수 있다

# 0001. 빌드 도구 없는 순수 HTML/CSS/JS 정적 사이트

상태: 결정 (2026-11-24)

## 맥락
제작은 Gemini가, 검수는 Claude가, 이후 문구 수정은 개발 초보인 오너가 한다. 무료 정적 호스팅에 올린다.

## 결정
`site/` 아래 순수 HTML/CSS/JS. 프레임워크·빌드·CDN 없음. 반복 내용(카드·경력)은 `site/data/*.json`을 JS로 그린다.

## 결과
- 좋음: 검수가 쉽고, 오너가 JSON·HTML 문구를 직접 고칠 수 있고, 어디든 그대로 올라간다
- 대가: 페이지 공통 머리·꼬리는 JS로 넣거나 복붙해야 한다. 체험형 데모는 실제 서버 대신 재생 방식이다

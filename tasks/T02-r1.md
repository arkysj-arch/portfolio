검수자: Claude · 결과: **불통과** (기준 2 반응형)
단계 이동, 승인 전 [다음] 막힘, JSON 값 일치, 이메일 비노출은 통과. 아래만 고친다.

## 고칠 파일 (이 밖은 건드리지 말 것)
`site/demos/influencer/demo.css`, `site/demos/influencer/demo.js`, `site/demos/influencer/index.html`

## 고칠 것
1. **모바일 가로 넘침 (필수)**: 375px에서 1단계·2단계 문서 폭이 529px로 넘친다. 원인은 후보 카드 묶음(`.candidate-card` 3개가 한 줄)과 점수 카드 묶음. 640px 이하에서는 카드가 **한 줄에 1개**씩 세로로 쌓이게 한다. 그리드라면 `grid-template-columns: 1fr`, 플렉스라면 `flex-wrap: wrap` + `min-width: 0`. 카드 안 긴 계정명은 `overflow-wrap: anywhere`.
2. **마지막 단계 버튼**: 5단계에서 [다음 단계 →]를 숨기고 [처음부터 다시 보기]와 [케이스로 돌아가기]를 보여준다. 1~4단계에서는 [처음부터 다시 보기]를 숨긴다.
3. **돌아가기 링크 중복**: 맨 위 안내 띠와 머리 메뉴에 "케이스로 돌아가기"가 두 번 있다. 안내 띠의 링크를 지우고 안내 문장만 남긴다.
4. **퍼널 숫자 중복**: 막대 안과 막대 오른쪽에 같은 숫자(예: 3명 / 3명)가 두 번 나온다. 막대 오른쪽 숫자만 남긴다.

## 완료 조건
1. 375·768·1280px 모든 단계에서 `document.documentElement.scrollWidth === clientWidth`가 되도록 CSS 작성
2. 위 2~4 동작 확인
3. 다른 동작(승인 게이트, 값) 그대로

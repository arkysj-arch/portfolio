# T14 — 숏폼 케이스에 두 번째 영상(16:9 제품 광고) 추가

목표: `/cases/shortform/` 페이지에 달바 비타 토닝 세럼 토너 20초 16:9 광고를 두 번째 사례로 넣는다. 기존 메디큐브 내용은 그대로 둔다.

먼저 읽을 것: `GEMINI.md`, `docs/source-notes.md` 4항의 "두 번째 제품 영상" 항목, `site/cases/shortform/index.html`, `site/cases/shortform/case.css`

## 만들 파일 (이 밖은 건드리지 말 것)
- `site/cases/shortform/index.html` — 아래 4곳만 고친다
- `site/cases/shortform/case.css` — 아래 클래스 2개만 추가

영상·포스터 파일은 이미 있다: `site/assets/video/shortform/dalba_vita_toning_serum_toner.mp4`, `site/assets/video/shortform/dalba-poster.webp`

## 고칠 내용 (문장은 아래 그대로 쓴다)

1. **맨 위 안내 상자** `.notice-text` 문장을 다음으로 바꾼다:
   > 메디큐브·달바와 무관한 비공식 포트폴리오 샘플입니다. 공식몰에 공개된 제품 사진을 썼고, 업로드·광고 집행은 하지 않았습니다.

2. **3단(AI에게 시킨 것)** 기존 `.role-table-wrap` 바로 **뒤**에 같은 모양의 블록을 하나 더 넣는다. 제목(`.subsection-title`): `역할 분담 — 두 번째 영상(16:9 제품 광고)`. 표 4줄:
   | 누가 | 무엇을 |
   |---|---|
   | Claude | 상세페이지·브랜드 조사, 장면표 6컷, 이미지·영상·음악 문안, 브라우저 조작, 프레임 검수, FFmpeg 편집 |
   | Nano Banana 2.1 | 컷별 기준 사진 (후보 12장 &rarr; 6장, 1장은 Nano Banana Pro) |
   | Google Flow 영상 (Omni 1.2 Flash) | 10초 영상 2편 + 4초 재시도 1편 |
   | Flow Music | 20초 연주곡 |

3. **4단(결과)** 기존 `.limits-wrap` 바로 **뒤**에 블록을 추가한다:
   - `<h3 class="subsection-title" style="margin-top: 2.5rem;">두 번째 영상: 16:9 제품 광고</h3>`
   - 기존과 같은 `.result-stats` 타일 4개: `20초` / `16:9 1080p 완성본` · `6컷` / `원료·사용 장면 포함` · `72크레딧` / `Flow 영상 생성(이미지 0)` · `12장 → 6장` / `기준 사진 후보 → 채택`
   - 이어서 `.limits-wrap` 모양의 한계 목록(제목 `한계`) 4줄:
     - 4번 컷의 캡이 실제(누르는 원판형 프레스 캡)와 달리 경첩 뚜껑으로 나옴 — 재생성 1회로도 해결되지 않음
     - 라벨의 작은 문구는 AI가 정확히 그리지 못함
     - 생성 원본 720p &rarr; 1080p 업스케일
     - 업로드 전이라 성과 지표(조회수·전환) 없음

4. **5단(직접 체험)** 기존 `.video-player-wrap` 바로 **뒤**, `.demo-action-box` **앞**에 두 번째 플레이어를 넣는다:
   ```html
   <div class="video-player-wrap video-player-wrap--wide">
     <video class="shortform-video shortform-video--wide" controls playsinline preload="none" poster="../../assets/video/shortform/dalba-poster.webp">
       <source src="../../assets/video/shortform/dalba_vita_toning_serum_toner.mp4" type="video/mp4">
       브라우저가 비디오 태그를 지원하지 않습니다.
     </video>
     <p class="video-caption">두 번째 영상: 달바 비타 토닝 세럼 토너 20초 광고(16:9). Google Flow 워터마크는 지우지 않았습니다.</p>
   </div>
   ```
   그리고 기존 메디큐브 플레이어의 `.video-caption` 맨 앞에 `첫 번째 영상: 메디큐브 부스터 프로 X2(9:16). `를 붙인다.

## case.css에 추가할 것
```css
.video-player-wrap--wide { max-width: 720px; margin-top: 2.5rem; }
.shortform-video--wide { max-width: 720px; aspect-ratio: 16 / 9; }
```
640px 이하 미디어 쿼리 안에도 `.video-player-wrap--wide, .shortform-video--wide { max-width: 100%; }` 추가.

## 반드시 지킬 것
- 위에 적은 문장 외의 설명 문단을 새로 쓰지 않는다
- `<head>`, 메타 태그(noindex 포함), 1·2단 본문, 기존 메디큐브 수치는 고치지 않는다
- 한국어만, 외부 라이브러리 없음

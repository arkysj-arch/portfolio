# T01 — 관통 뼈대: 메인 + 인플루언서 케이스 + 데모 자리

목표: 메인 → 인플루언서 케이스 → 데모 자리까지 끝까지 눌러 갈 수 있는 사이트 뼈대를 디자인 규칙대로 만든다.

먼저 읽을 것: `GEMINI.md`, `SPEC.md`(2·3·4·6항), `GLOSSARY.md`, `docs/source-notes.md`

## 만들 파일 (이 밖의 파일은 건드리지 말 것)
- `site/index.html` — 메인
- `site/assets/css/style.css` — 공통 스타일 (색·글꼴·간격 변수, 카드, 큰 숫자, 배지, 케이스 5단 구조)
- `site/assets/js/main.js` — `data/projects.json`을 읽어 카드 목록을 그림
- `site/data/projects.json` — 케이스 5개 (id, 제목, 한 줄 설명, 상태 배지, 링크). 내용은 SPEC 3항에 있는 것만
- `site/cases/influencer/index.html` — 케이스 페이지 (SPEC 3-1 내용을 5단 구조로)
- `site/demos/influencer/index.html` — "체험형 데모 준비 중" 자리 + 케이스로 돌아가기

## 반드시 지킬 것
- 메인 첫 화면: 한 줄 소개(SPEC 1항 포지셔닝) + 핵심 숫자 3개(17년 차 / 루킨스 연매출 2.2배 / AI 자동화 도구 직접 구축) + 이메일 자리(`[이메일 확인 필요]`)
- 카드 순서: 인플루언서 → SJ 프루프 → SJ RANK → 숏폼 → 오케스트레이션. 인플루언서 외 카드는 링크만 두고 페이지는 만들지 않는다
- 상태 배지: `프로토타입`, 숏폼만 `진행 중`
- 케이스 페이지는 SPEC 3-1의 문장과 숫자만 쓴다. "⚑" 표시 문장은 그대로 쓰되 다듬어도 뜻을 바꾸지 말 것
- 폰트: 지금은 `font-family: "Pretendard", system-ui, sans-serif`만 지정 (폰트 파일은 나중에 Claude가 넣는다)
- 상대 경로만 사용 (GitHub Pages 하위 경로에서도 동작하도록)

## 완료 조건
1. `site/index.html`을 파일로 열면 카드 5개가 보이고, 인플루언서 카드 → 케이스 → 데모 자리 → 돌아가기가 모두 동작
2. 375px·768px·1280px 폭에서 가로 스크롤 없음
3. 숫자·주장은 모두 SPEC·source-notes에 근거, 근거 없으면 `[확인 필요]`
4. 전화번호·주소·실존 인플루언서 이름 없음
5. 외부 라이브러리·CDN 없음

참고: `main.js`가 `fetch`로 JSON을 읽으면 파일로 직접 열 때 막힐 수 있다. 그 경우를 대비해 JSON 내용을 `main.js` 안 기본값으로도 넣어 두고, 보고서에 적을 것.

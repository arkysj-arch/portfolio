# T04 — SJ RANK 케이스 + 화면 둘러보기 데모

목표: SEO 도구를 "진단에서 끝내지 않고 실행 순서까지 주는 도구"로 보여주고, 실제 프로그램 화면 5장을 탭으로 넘겨 보게 한다.

먼저 읽을 것: `GEMINI.md`, `SPEC.md` 3-3, `docs/source-notes.md` 3항, `site/data/demo-sjrank.json`, `site/cases/influencer/index.html`(구조·클래스 그대로 따라 할 것), `site/assets/css/style.css`

## 만들 파일 (이 밖은 건드리지 말 것)
- `site/cases/sj-rank/index.html` — 케이스 (인플루언서 케이스와 같은 머리·꼬리·5단 구조·클래스)
- `site/demos/sj-rank/index.html` — 화면 둘러보기 데모
- `site/demos/sj-rank/demo.js`, `site/demos/sj-rank/demo.css`

## 케이스 내용
- 배지 `프로토타입`, "케이스 03"
- 문제·판단·AI에게 시킨 것: SPEC 3-3 문장 그대로(다듬어도 뜻 유지)
- AI에게 시킨 것 아래에 `demo-sjrank.json`의 `beyond` 3개를 카드로 ("진단 다음까지")
- RankSeed 한 단락: SPEC 3-3 "보조" 문장. 외부 서비스 이름은 쓰지 않는다 ("공개 서비스의 흐름만 참고")
- 결과: "실행 플랜·사이트 감사·키워드·순위 추적·발행까지 한 도구, 데모 데이터로 검증 (실사용 수치 없음 — 프로토타입)" + 대표 화면 1장(`plan.webp`, `loading="lazy"`, 가로 100%, 둥근 모서리, 테두리)
- 직접 체험: 데모 페이지 버튼

## 데모 (화면 둘러보기)
- 맨 위 안내 띠: JSON `notice`
- 탭 5개(`screens[].tab`), 첫 탭 "실행 플랜"이 기본. 탭은 `<button role="tab">`, 선택 `aria-selected`
- 선택한 탭: 화면 이미지(`img`, `alt`) + 그 아래 "여기를 보세요" 목록(`points`)
- 이미지를 누르면 새 창으로 원본 크기 보기
- 모바일: 탭은 가로로 밀어 보는 줄(이 줄 안에서만 가로 스크롤 허용, 문서 전체는 넘치면 안 됨), 이미지는 화면 폭에 맞춤
- 끝에 [케이스로 돌아가기]
- 경로: JSON의 `img`는 `site/` 기준이므로 데모 페이지에서는 `../../` + img

## 반드시 지킬 것
- 화면 문장·숫자는 JSON·SPEC·source-notes에 있는 것만
- JSON 못 읽으면 안내 문구만 (기본값 복사본 금지)
- 한국어만(SEO, H1, CSV, URL 같은 약어 허용), 외부 라이브러리 없음

# T06b — 숏폼 케이스를 "진행 중" → "프로토타입"으로 (완성 영상 반영)

목표: 첫 제품 숏폼이 완성됐다. 케이스에 영상을 넣고, 결과를 실측 숫자로 바꾼다. 이 케이스의 강점은 "만들 수 있었지만 권리 때문에 멈춘 판단"이다 — 그 판단을 숨기지 말고 앞에 세운다.

먼저 읽을 것: `GEMINI.md`(특히 6항 문장 규칙), `docs/source-notes.md` 4항 맨 아래 "첫 제품 숏폼 완성", 지금의 `site/cases/shortform/index.html`

## 고칠 파일 (이 밖은 건드리지 말 것)
- `site/cases/shortform/index.html`
- `site/cases/shortform/case.css`

## 고칠 것
1. 배지 `진행 중` → `프로토타입`. 맨 위 "진행 상태" 상자를 **안내 상자**로 바꿈: "메디큐브와 무관한 비공식 포트폴리오 샘플입니다. 공식몰에 공개된 제품 사진을 썼고, 업로드·광고 집행은 하지 않았습니다."
2. 01 문제: 지금 문장 유지 + 한 문장 추가: "목표는 월 1~4편, 편당 AI 비용 $20 이하였습니다."
3. 02 판단: 원칙 3개 유지. 그 아래 **"만들면서 내린 판단"** 목록 4개 추가 (source-notes의 판단 항목을 짧게): 약관 먼저 / 제품은 AI가 다시 그리지 않음 / 권리 동의를 대신하지 않음 → 실제 사진에 움직임 / 의료 효과 표현 제외
4. 03 AI에게 시킨 것: 흐름 3단계 유지. 그 아래 역할 표(누가 / 무엇을) 4줄 — source-notes "AI에게 시킨 것" 그대로 줄여서
5. 04 결과: 상태 표를 지우고 실측 숫자 타일 4개: `20초` 9:16 완성본 / `$0` AI 현금 비용(상한 $20) / `약 61분` 사진 수집→완성(승인 대기 포함) / `53.8초` 최종 합성. 그 아래 "한계" 3줄(source-notes 그대로)
6. 05 직접 체험: 비활성 버튼 대신 **세로 영상 플레이어**
   - `<video controls playsinline preload="none" poster="../../assets/video/shortform/poster.webp">` + `<source src="../../assets/video/shortform/medicube_booster_pro_x2.mp4" type="video/mp4">`
   - 최대 폭 360px, 가운데 정렬, 둥근 모서리. 자동 재생 금지
   - 아래 작은 글씨: "Google Flow 워터마크는 약관에 따라 지우지 않았습니다."

## 반드시 지킬 것
- 숫자는 source-notes에 있는 실측값만. 성과(조회수·전환)는 없다고 쓴다
- 문장 규칙(제목 반복 금지, 꾸밈말 금지) 지킬 것

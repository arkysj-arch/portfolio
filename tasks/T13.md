# T13 — 마감 기본기: 설명 태그 · 파비콘 · 404 · 공유 이미지 원판

목표: 링크를 카톡·메일로 보냈을 때와 브라우저 탭에서 "완성된 사이트"로 보이게 한다.

먼저 읽을 것: `GEMINI.md`, `site/assets/css/style.css`(색 변수), `site/index.html`

## 만들 파일 (이 밖은 건드리지 말 것)
- `site/favicon.svg` — 32x32 기준 단순한 모양: 남색(#14213D) 둥근 사각형 안에 아이보리(#F7F4EE) 글자 "윤". 외부 폰트 없이 `font-family: sans-serif`
- `site/404.html` — "찾는 페이지가 없습니다" + [메인으로] 버튼. 404 화면은 어느 깊이의 주소에서도 뜨기 때문에 외부 CSS 파일 경로가 깨질 수 있다. 그래서 **CSS는 `<style>` 안에 직접**(색·글꼴·버튼 정도만) 넣고, 외부 파일을 불러오지 않는다. 메인 버튼 링크는 Claude가 배포 때 저장소 주소로 바꾸므로 지금은 `href="./"`
- `site/og/og.html` — 공유 이미지 원판(정확히 1200×630px 한 화면). 아이보리 바탕, 왼쪽 위 작은 글씨 "포트폴리오", 큰 제목 "AI 팀을 지휘해 이커머스·마케팅 성과를 만드는 총괄", 아래 "윤성조 · 뷰티디바이스·화장품 이커머스 17년", 오른쪽 아래 포인트 색 띠에 케이스 5개 이름(인플루언서 자동화 · SJ 프루프 · SJ RANK · 숏폼 · 오케스트레이션). 스크롤·여백 없이 body가 1200×630 고정
- 아래 HTML 파일들의 `<head>`에 **추가만** (다른 줄은 고치지 말 것):
  - `site/index.html`, `site/cases/*/index.html`(5개), `site/demos/*/index.html`(3개)
  - 각 파일: `<meta name="description" content="...">` (페이지별 한 문장, 그 페이지 본문에 있는 말로만, 80자 이내), `<link rel="icon" href="(상대경로)favicon.svg" type="image/svg+xml">`, `<meta name="theme-color" content="#F7F4EE">`
  - **`site/cases/sj-proof/`, `site/cases/shortform/`, `site/demos/sj-proof/` 세 파일에만** `<meta name="robots" content="noindex">` 추가 (실존 브랜드 비공식 샘플이라 검색 노출 제외)

## 반드시 지킬 것
- 설명 문장은 각 페이지에 이미 있는 문장에서만 고른다 (새 사실 금지)
- 한국어만, 외부 라이브러리·폰트 없음

## 완료 조건
1. 모든 페이지에 파비콘·설명 태그 1개씩 (중복 없음)
2. noindex는 정확히 3개 파일
3. `og/og.html`을 1200×630 창으로 열면 잘림 없이 꽉 참

# T03 — 메인 하단: 경력 요약 · 그 밖의 작업 · 연락

목표: AI 프로젝트 아래에 경력 근거를 짧고 강하게 보여주고, 연락 수단으로 끝낸다.

먼저 읽을 것: `GEMINI.md`, `site/data/career.json`, `site/index.html`, `site/assets/js/main.js`, `site/assets/css/style.css`

## 만들 파일 (이 밖은 건드리지 말 것)
- `site/index.html` — 프로젝트 섹션 뒤에 섹션 3개 추가, 머리 메뉴에 "경력" 추가
- `site/assets/js/main.js` — `data/career.json`을 읽어 아래 섹션을 그리는 함수 추가 (기존 카드 함수는 그대로)
- `site/assets/css/style.css` — 새 섹션 스타일을 **파일 끝에 추가만** (기존 규칙 수정 금지)

## 섹션
1. **경력** (`id="career"`)
   - 제목 "17년, 직접 매출을 만든 경력" + `summary`
   - `highlights` 5개를 큰 숫자 타일로 (모바일 2열, 데스크톱 5열 또는 3+2)
   - `jobs` 3개를 세로 타임라인: 회사 · 역할 · 기간 + 핵심 3~4줄
   - `earlier` 한 줄
   - `downloads`: `href`가 null이면 버튼을 비활성 모양으로 두고 `note`를 작게 표시
2. **그 밖의 작업** (`id="others"`): `others` 목록을 링크 카드로 (새 창 `target="_blank" rel="noopener"`). 항목이 늘어도 그대로 나오도록
3. **연락** (`id="contact"`): `contact.email`이 null이면 `[이메일 확인 필요]` 표시. 지금 히어로 안의 `id="contact"`는 이 섹션으로 옮긴다(히어로에는 "연락하기" 버튼으로 `#contact` 이동)

## 반드시 지킬 것
- 화면 숫자·문장은 `career.json`에 있는 것만. 꾸밈말(최고의, 탁월한 등) 금지
- JSON을 못 읽으면 경력 섹션에 "경력 정보를 불러오지 못했습니다"만 표시 (기본값 복사본 금지 — 데이터가 두 군데 생기면 어긋난다)
- 한국어만, 외부 라이브러리 없음, 전화번호 등 연락처는 이메일만

## 완료 조건
1. 머리 메뉴 프로젝트·경력·연락 이동 동작, 프로젝트 카드 기존 동작 유지
2. 화면 값이 `career.json`과 일치
3. 375·768·1280px 가로 스크롤 없음
4. 유튜브 링크 새 창으로 열림

# T07 — SJ 프루프 케이스 + 체험형 데모

목표: "AI가 상세페이지를 빨리 만든다"가 아니라 **"AI가 지어내지 못하게 만들었다"**를 보여준다. 데모의 주인공은 '일부러 뺀 주장 8건'과 '모든 사실의 출처 주소'다.

먼저 읽을 것: `GEMINI.md`(6항 문장 규칙), `docs/source-notes.md` 1항 맨 아래 "공개용 샘플", `site/data/demo-sjproof.json`, `site/cases/influencer/index.html`·`site/demos/influencer/`(구조·단계 UI 따라 할 것)

## 만들 파일 (이 밖은 건드리지 말 것)

## 케이스 (케이스 02, 배지 `프로토타입`)
- 맨 위 안내 상자: JSON `notice`
- 1 문제 / 2 판단: source-notes "공개용 샘플"의 문제·판단 그대로 짧게 (판단은 목록 5개)
- 3 AI에게 시킨 것: 흐름 — 공식몰 리서치 → 사실 목록(출처 주소) → 기획·문구(근거 번호) → 자동 검사(의료기기 오인·조건 누락·표절) → 조립·860px 출력
- 4 결과: JSON `compare`를 표(항목 / 이전 시험작 / 이번)로 + `compare_note` 작은 글씨. 위에 숫자 타일 3개: `78/78` 출처 주소가 붙은 사실 / `0` 합성 자료 / `8건` 근거가 약해 뺀 주장. 아래 한계 3줄(source-notes)
- 5 직접 체험: 데모 버튼

## 데모 (4단계, 인플루언서 데모와 같은 단계 UI·이전/다음)
| 단계 | 보여줄 것 |
|---|---|
| 1 입력·리서치 | 제품명, `input.photos`, `input.research`, 못 구한 자료 `not_available` 목록("없는 건 지어내지 않고 비워 둠") |
| 2 사실 목록 | 총 `facts_total`개 · 출처 주소 `facts_with_url`개 · 합성 `facts_synthetic`개 타일 + `facts_sample` 카드(번호, 종류, 문장, 출처 주소는 `http`로 시작하면 링크 `target=_blank rel="noopener"`, 아니면 글자만) |
| 3 검사 | **일부러 뺀 주장 `excluded` 8건**(취소선 문장 + 이유) ← 이 단계 핵심. 그 아래 퍼널 8칸(`funnel`, 있음=채움) · 망설임 질문 12/13 (92%) · 함정 시험 10/10 · 오류 0. 마지막에 "판매자에게 물을 것" `seller_questions` 5개 |
| 4 완성 페이지 | 휴대폰 모양 틀(폭 최대 390px, 높이 70vh, 안에서 세로 스크롤) 안에 `page.slices` 이미지를 순서대로 `loading="lazy"`로 쌓음. 이미지 사이 틈 없게(`display:block`). 아래 "860px × 29,448px 실제 출력물" 문구는 JSON `page.width`·`page.height`로 |

- 종류 이름은 한국어로 보여줄 것: notice=상품정보고시, brand_page=공식 상세 문구, evidence=시험·인증, official_photo=공식 사진, price=가격, policy=배송·교환
- 경로: JSON의 `src`는 `site/` 기준 → 데모에서는 `../../` 붙임
- JSON 못 읽으면 안내 문구만

## 완료 조건

4. 숫자는 JSON·source-notes와 일치

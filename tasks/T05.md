# T05 — 오케스트레이션 케이스 (이 사이트를 만든 방식)

목표: "AI 팀을 지휘한다"가 말이 아니라 실제 기록임을 보여준다. 이 케이스 자체가 포지셔닝의 증거다.

먼저 읽을 것: `GEMINI.md`, `site/data/orchestration.json`, `site/cases/influencer/index.html`(구조·클래스 따라 할 것), `site/assets/css/style.css`

## 만들 파일 (이 밖은 건드리지 말 것)
- `site/cases/orchestration/index.html`
- `site/cases/orchestration/case.css` (필요할 때만, 공통 style.css 뒤에 불러옴)

## 구성 (5단 구조를 이 케이스에 맞게)
1. **문제**: "AI에게 일을 시키면 빠르지만, 그대로 믿으면 틀린 숫자와 깨진 화면이 그대로 나간다."
2. **판단**: 역할을 나눈다 — `roles` 3개를 카드로. 그리고 "만든 AI가 스스로 '통과'라고 해도, 지휘자가 직접 띄워 재고 근거와 대조한다"
3. **AI에게 시킨 것**: `process` 4단계를 흐름도(가로, 모바일에서는 세로)로
4. **결과**: `stats_m1`을 숫자 타일 4개로 — 작업 3개 / 왕복 5회 / 한 번에 통과 1개 / 지휘자가 직접 고친 줄 4줄. 그 아래 `cases` 4개를 펼침 카드로: 제목 + 작업 이름, 펼치면 "무슨 일이 있었나 / 어떻게 지시했나 / 결과" 세 칸. `<details><summary>` 사용
5. **직접 체험**: 데모 페이지 대신 "이 사이트 자체가 결과물입니다" 문장 + 메인으로 가는 버튼 + 다른 케이스 링크(인플루언서, SJ RANK)

## 반드시 지킬 것
- 문장과 숫자는 `orchestration.json`에서만. JSON을 JS로 읽지 말고 **HTML에 직접 써 넣는다** (이 페이지는 고정 기록이므로)
- 배지 `프로토타입` 대신 `기록` 배지(포인트 색 테두리) — 스타일은 case.css에
- "케이스 05"
- 과장 금지(혁신적, 완벽한 등). 실패와 수정 사실을 숨기지 않는다 — 그게 이 케이스의 핵심
- 한국어만, 외부 라이브러리 없음

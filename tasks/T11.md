# T11 — 웹 공개용 포트폴리오 PDF 원판 (인쇄용 HTML)

목표: 지원서에 첨부할 수 있는 A4 PDF. Claude가 이 HTML을 브라우저 인쇄로 PDF로 만든다. 사이트와 같은 데이터를 쓰므로 내용이 어긋나지 않는다.

먼저 읽을 것: `GEMINI.md`, `site/data/career.json`, `site/data/projects.json`, `docs/source-notes.md`(각 케이스 결과 숫자), `site/assets/css/style.css`(색만 참고)

## 만들 파일 (이 밖은 건드리지 말 것)
- `site/print/portfolio.html` — 인쇄 전용 한 파일 (CSS는 `<style>` 안에)

## 구성 (A4 세로, 여백 14mm, `@page { size: A4; margin: 14mm }`)
1. **1쪽 — 요약**: 이름 "윤성조" · 한 줄 포지셔닝("AI 팀을 지휘해 이커머스·마케팅 성과를 만드는 총괄") · 이메일 `career.json`의 `contact.email` · 사이트 주소 자리 `[사이트 주소]`(배포 후 Claude가 채움) · `summary` · `highlights` 5개 숫자 타일 · 경력 3개사(회사·역할·기간·핵심 2줄씩) · `earlier` 한 줄
2. **2쪽 — AI 프로젝트 5개**: 케이스마다 한 덩어리(쪽 안에서 끊기지 않게 `break-inside: avoid`): 이름 · 상태 배지 · 한 줄 설명(projects.json `summary`) · 결과 숫자 2~3개(source-notes에서만: 인플루언서 = 자동 테스트 42개·5단계 흐름 / SJ 프루프 = 출처 주소 78/78·합성 자료 0·뺀 주장 8건 / SJ RANK = 화면 5개·진단 1회 약 $0.04 / 숏폼 = 20초 9:16·AI 현금 비용 $0 / 오케스트레이션 = M1 작업 3개·왕복 5회) · "체험: [사이트 주소]/cases/<id>/"
   - SJ 프루프·숏폼 아래 작은 글씨: "메디큐브와 무관한 비공식 샘플, 공식몰 공개 정보 기반"
3. 꼬리(각 쪽 아래는 생략 가능): "이 문서와 사이트는 Claude(지휘)와 Gemini(제작)로 만들었습니다."

## 반드시 지킬 것
- 숫자·문장은 위 데이터 파일과 source-notes에서만. JSON은 **JS로 읽지 말고 HTML에 직접 써 넣는다** (인쇄 때 확실히 나오도록)
- 전화번호·주소·생년월일 없음
- 화면으로 열어도 A4 폭(210mm) 종이처럼 보이게, 인쇄하면 정확히 **2쪽**
- 한국어만, 외부 폰트·라이브러리 없음 (`font-family: "Malgun Gothic", "Apple SD Gothic Neo", sans-serif`)

## 완료 조건
1. 인쇄 미리보기 2쪽, 내용 잘림 없음
2. 모든 숫자가 데이터와 일치
